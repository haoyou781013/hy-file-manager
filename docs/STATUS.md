## 三、动手前的建议

**优先做播放器阶段 3（后台播放）**，理由：

1. 它是**唯一剩下的用户能明确感知的功能缺口**
   —— 看视频切出去就停，这在实际使用中很频繁
2. 它是阶段 4（画中画）的前置，做完能连带解锁
3. 风险虽高但**边界清晰**：改动集中在 `PlayerCore` → `PlaybackService` 的迁移，
   `PlayerSettings` / `PlayerUiState` / `GestureController` 都不受影响

**不建议优先做的**：

- God Class 继续拆 —— 纯结构，无功能收益，风险与收益不成比例
- 文本编辑器重构 —— 范围太大，应单独立项
