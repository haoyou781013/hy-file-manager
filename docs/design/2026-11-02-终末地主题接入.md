# 终末地主题接入说明

> 来源技能包：https://github.com/hhikr/endfield-ui-skill（MIT 无 License 声明，字体 Saira 为 SIL OFL）
> 接入日期：2026-11-02

## 这是什么

一套「终末地风味工业科技感」的设计规范，原为 agent 用的 skill 包，
提供 tokens（颜色/字号/动效曲线）、各平台代码指南与示例。

本地副本：`/sdcard/Android/haoyou781/12-杂项/skills/endfield-ui-skill/`

## 与现有「工业风格」的区别

| | 工业风格（原有） | 终末地（新增） |
|---|---|---|
| 底色 | 深色 `#121212` | 纸感 `#F4F4F2` / 墨色 `#191919`（两套） |
| 强调色 | 琥珀 `#FFB300` | **酸性黄 `#FFFA00`** |
| 形状 | 圆角 | 直角 + 切角（切角=可点击） |
| 字体 | 系统字体 | **Saira 可变宽体** + 系统 CJK |
| 动效 | 常规 | 短、硬、机械（snap/mech 曲线） |

**两者并存**，由 设置 → 个性化 → 界面主题 的第三项「终末地」选择。

## 已实现

### 1. 三套主题（values/themes.xml）
```
Theme.HYFileManager.Endfield         DayNight
Theme.HYFileManager.Endfield.Light   浅（纸）
Theme.HYFileManager.Endfield.Dark    深（墨）
```

关键约束（来自 skill 的固定规则）：
- **主色给墨色而非黄色** —— Material 默认部件（光标/焦点线/进度条/复选框）
  用 `colorPrimary` 画线，黄线在浅色纸上不可见。黄色只通过 `colorSecondary`
  暴露给自定义部件手动使用。
- 红色 `colorError` **只给删除**。
- 强调色只做填充，不铺底。

### 2. 色板（values/colors_endfield.xml）
完整对应 `tokens.json` 的 `color.light` / `color.dark`：
paper / panel / ink / ink2 / rule / chip / signal / onSignal /
trace / tagBg / tagFg / danger / scrim + 三色条 tri_a/b/c。

### 3. 字体
- `res/font/saira.ttf`（472KB，可变字体，来自 skill 的 templates/flutter/fonts/）
- `res/font/saira_family.xml`（4 个字重 400/600/700/800）
- 三个终末地主题均设 `android:fontFamily=@font/saira_family`
- 许可证 `assets/Saira-OFL.txt`（SIL OFL，允许闭源分发）

**为什么能覆盖全局**：项目中 48 处 `setTypeface` 调用里，
27 处是 `setTypeface(null, BOLD)` —— 传 null family 只改字重，不覆盖主题字体；
其余是 `MONOSPACE`（终端/编辑器，应当保留）。

## 未实现（skill 里还有，本次没做）

| 项 | 说明 |
|---|---|
| 切角按钮 | 需写自定义 Drawable（`CutCornerShape` 等价物），工作量大 |
| `//` 眉标 + 中英成对标题 | 需要改所有页面标题布局 |
| 编号标签 `No.024` | 需要改列表项布局 |
| 三色条 | 需要改顶栏 |
| 记录行（编号/日期/名称/计数 + 细线） | 需要改列表项布局 |
| 机械动效曲线（snap/mech） | 可加到现有动画，但需逐个调整 |

本次只做了**换色 + 换字体**，即「不改变布局结构的前提下让主题有终末地的底子」。
深度改造（切角、眉标、编号标签）需要单独排期。
